# Manuscript

This folder is the location for the final science report. The only required manuscript file is `science_report.pdf`; adding LaTeX is optional. The analysis code and included results do not depend on either file.

Recommended files:

- `science_report.pdf` — final report.
- `science_report.tex` — optional LaTeX source.

No further analysis tables or phase files need to be uploaded here. The code release reproduces the current report's conclusion-linked numerical analyses. See [claim-to-code coverage](../docs/CLAIM_TRACEABILITY.md) and the [verification reports](../results/verification/).
